# Libraries_Solutions_saya38t
My libraries and solutions for competitive programming.

競技プログラミングの提出コードと再利用用コードを管理しています。

## 構成・運用方針

- `template.cpp`：提出時に使用する共通テンプレート。
- `algorithm/`：コピー＆ペースト用のアルゴリズム実装集。利用時は提出コードに該当ファイルのURLを記載します。
- その他のコードを再利用する場合は、参照元のAtCoder提出URLを記載します。

## ライセンス

自身が著作権を有するコードは、[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/deed.ja) に基づき著作権を放棄しています。
複製・改変・再配布は自由で、出典表示も不要です。

他者のコードを利用する場合は、利用条件を確認し、出典とライセンスを明記します。

## AtCoderでの運用方針

- **コーディング**：[Clion_practice](https://t.co/etZdgHGqv5) を一時的な作業場所として使用する。
- **ライブラリ・精進記録**：本リポジトリで管理する。
- **コピー元URL**：原則として本リポジトリのURLを記載する。必要に応じて、AtCoder上の自分の提出URLも使用する。

CLionの操作と、十分に整備されていない開発環境での作業に慣れることが目的です。
